ВВЕДЕНИЕ
В условиях роста популярности онлайн-шопинга и дистанционного дизайна интерьеров возникает проблема: пользователь не может оценить, как мебель или предмет декора будут смотреться в его собственном пространстве до момента покупки. Традиционные методы (фотографии, 2D-планировщики) не дают полного представления о размере, стиле и сочетаемости объектов с обстановкой.
В рамках дипломной работы разрабатывается мобильное приложение с использованием дополненной реальности (AR) для Android, которое позволяет в реальном времени размещать виртуальные 3D-модели мебели в помещении пользователя, интерактивно управлять ими (перемещать, вращать, масштабировать) и сохранять созданные сцены. Акцент в работе делается на исследовании и реализации эффективных подходов к управлению в AR-среде и достижению качественной визуализации.
На текущем этапе реализована базовая AR-сессия, система обнаружения поверхностей и прототип модуля интерактивного управления. Ведется работа над интеграцией каталога моделей и системой визуализации.
 
Постановка задачи
Цель: 
Разработка прототипа мобильного AR-приложения для интерактивного моделирования обстановки с фокусом на исследование методов управления и визуализации.
Задачи: 
Провести анализ существующих AR-платформ (ARCore, ARKit) и выбрать технологический стек.
Спроектировать модульную архитектуру AR-приложения.
Реализовать базовую AR-сессию с обнаружением горизонтальных плоскостей.
Разработать систему интерактивного управления виртуальными объектами (жесты тап, drag, pinch).
Создать каталог 3D-моделей мебели и механизм их загрузки в сцену.
Исследовать и реализовать методы улучшения визуализации (освещение, материалы).
Реализовать систему сохранения и загрузки состояния AR-сцены.
Разработать пользовательский интерфейс, адаптированный для AR-взаимодействия.
Провести тестирование и оценку производительности прототипа.
1	Текущий статус проекта
На момент подготовки данного отчета выполнены следующие этапы: 
Завершен анализ предметной области и выбор платформы (ARCore для Android).
Спроектирована общая модульная архитектура приложения.
Реализована базовая AR-сессия с использованием ARCore SDK: корректно запускается, обнаруживает и визуализирует горизонтальные плоскости (пол, стол).
Реализована основа системы управления: обработка тапа для размещения тестового 3D-объекта (куб) на обнаруженной плоскости.
Начата реализация жеста drag для перемещения объекта.
Подготовлена структура проекта в Android Studio (Kotlin).
2	Общая архитектура приложения
	Приложение построено по принципу Model-View-ViewModel (MVVM) для четкого разделения логики AR, данных и интерфейса. Основные компоненты:
ARActivity / ARFragment: Основная активность, содержащая AR-сессию (ArSceneView).
ARSessionManager: Центральный модуль, управляющий жизненным циклом ARCore-сессии, обработкой плоскостей и размещением Anchor.
GestureHandler: Отвечает за обработку касаний и жестов пользователя (тап, drag, pinch), преобразуя их в команды трансформации для виртуальных объектов.
ModelManager: Загружает 3D-модели из каталога (формат .glb), управляет их кэшированием и создает Renderable-объекты для ARCore.
SceneState: Модель данных, хранящая текущее состояние сцены (список объектов, их позиции, повороты, масштаб).
SceneSerializer: Отвечает за сериализацию SceneState в JSON-файл и обратно для сохранения/загрузки.
UICatalogFragment / ControlsFragment: Пользовательский интерфейс для выбора моделей и управления сценой.
3	Реализация основных модулей
3.1	Модуль AR-сессии и управления
Модуль ARSessionManager инкапсулирует работу с ARCore:
Инициализирует и настраивает Session с включенным PlaneDetectionMode.HORIZONTAL.
Создает AnchorNode в точке пересечения луча от касания с обнаруженной плоскостью.
Прикрепляет к AnchorNode выбранную 3D-модель, делая ее частью AR-мира.

3.2	Модуль обработки жестов
Модуль GestureHandler использует GestureDetector Android для распознавания:
Одиночное касание (MotionEvent.ACTION_DOWN): Запускает процесс hitTest для поиска плоскости и создания Anchor.
Перемещение (MotionEvent.ACTION_MOVE): При активном перетаскивании объекта вычисляет новую позицию на плоскости и обновляет трансформ AnchorNode.
На данный момент реализовано размещение и базовая логика перемещения. Ведется работа над распознаванием жеста pinch для масштабирования.

 
3.3	Модуль каталога 3D-моделей
Для каталога подготовлена структура папок assets/models/. Проведен поиск бесплатных моделей мебели на платформах (Sketchfab, Free3D). Выбранные модели конвертируются в .glb и оптимизируются (уменьшение полигонов, сжатие текстур) с помощью Blender для обеспечения плавной работы в AR.

3.4	Модуль визуализации
Ведется исследование возможностей ARCore по визуализации:
Light Estimation: Изучается API EnvironmentalHdrLightEstimate для получения параметров окружающего освещения и их применения к PBR-материалам моделей.
PBR-материалы: Модели подбираются/готовятся с корректно настроенными картами albedo, roughness, metallic для достижения реалистичного вида.
4	Анализ нейронных сетей для классификации контента
Для реализации были рассмотрены следующие ключевые технологии:
1.  ARCore (Google) vs ARKit (Apple):
ARCore: Кроссплатформенная поддержка множества Android-устройств. Открытая документация. Идеально для целевой аудитории. Выбран как основа.
ARKit: Высокая стабильность и производительность, но ограничена экосистемой Apple. Не подходит для массового покрытия в рамках данного диплома.
2. Фреймворки для работы с 3D в ARCore:
Sceneform (устаревший): Предоставлял высокоуровневый API, но официально не поддерживается.
Filament / ARCore Renderable API: Низкоуровневый, но гибкий и поддерживаемый путь. Требует ручной работы с .glb моделями. Выбран для полного контроля над визуализацией.
3. Форматы 3D-моделей:
glTF 2.0 / .glb: Стандарт де-факто для веба и AR. Поддерживает PBR-материалы, анимации, эффективное сжатие. Выбран как основной формат.
.fbx, .obj: Широко распространены, но менее оптимизированы для реального времени в мобильных AR.
5	Предварительный выбор нейросети
На основе проведенного анализа сформирован следующий стек технологий:
Язык программирования: Kotlin (официальный для Android).
AR SDK: Google ARCore.
3D Рендеринг: Filament движок через ARCore Renderable API.
Формат 3D-моделей: .glb (binary glTF).
Архитектура приложения: MVVM.
Сериализация данных: Kotlinx.serialization для JSON.
Данный стек обеспечивает баланс между производительностью, контролем над визуализацией и поддержкой со стороны Google.

1.	Завершение модуля жестов: Полная реализация и отладка жестов drag и pinch.
2.	Интеграция каталога моделей: Загрузка .glb моделей через ModelRenderable.builder(), создание UI-каталога.

5.	Разработка пользовательского интерфейса: Создание удобного каталога и панели управления.

На текущем этапе дипломной работы выполнено обоснование выбора темы, проведен анализ технологий, спроектирована архитектура и реализован базовый функционал AR-приложения: обнаружение плоскостей и интерактивное размещение объектов.
